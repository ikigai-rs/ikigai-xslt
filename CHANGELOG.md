# Changelog

## 0.7.1

This patch builds again for a fresh resolve on the ikigai-core 0.3 line. It
keeps xrust below 2.4, which introduced incompatible API changes. The
ikigai-xslt API is unchanged.

### Upgrading from 0.7.0

Update the ikigai-xslt dependency to 0.7.1. The crate has no persisted state,
so there is nothing to migrate.
